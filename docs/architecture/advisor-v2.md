# Supervisor 与领域槽位流水线

生产入口 `build_advisor_graph` 编译 `advisor-v2`。主控负责计划、依赖、执行预算和结果覆盖；股票、商品和组合各自拥有 Pydantic 槽位、补丁合并及执行校验。旧图只保留为显式回归对照，不恢复旧业务轮次。

```text
Supervisor → 领域槽位抽取／校验／标的解析 → Supervisor → Worker → Supervisor
                                                        ↓
                                      适配性 → 结构化答案 → 校验 → 持久化 → SSE
```

任务按 ID 隔离，依赖满足后才能执行。默认最多三批 Worker、八个不同任务，每任务最多补查一次；重复原查询不属于新补查方法。执行超时由 `AGENT_TURN_TIMEOUT_SECONDS` 控制，默认 120 秒。等待用户时结束执行段。

## 槽位与普通澄清

会话数据库保存 `version/slots/pending_tasks`。每个领域包含多个上下文和当前活动上下文；任务引用自己的上下文，不能用一个共享字典承载同域并行任务。补丁显式区分设置、清除和数组追加。

明确追问继承槽位；切换对象／场景重建上下文，只有明确要求同样分析才沿用条件。观察时间范围与投资期限不同，日期按上海时区规范化。用户风险画像从数据库确认值读取，领域提取器无写权限。

槽位不足时 Worker 不执行，主控保存待办并发布普通澄清回答，本轮完成。用户下一条聊天可以补充待办或换话题；换话题取消待办，历史上下文仍保留。多个待办逐项处理。新轮次刷新必要依赖，旧证据不自动变成当前证据。

画像确认与方案采纳保持结构化 `interrupt`。只有明确生成方案的请求才进入配置引擎；模拟采纳必须来自用户选择。查询和诊断不生成方案。跨轮补答只更新当前待办，依赖任务复用自身确认槽位刷新证据，不能把补答重新解释为前置任务的新条件。

## 证据与发布

工具证据隔离客户、会话、请求和任务，只有明确依赖可共享。事实核验关联字段路径、标的、指标、数值、单位和截止时间；工具缺数据或不支持历史范围／额外约束时明确警告，不能静默忽略。

商品推荐使用结构化代码与真实商品证据，最终允许集合由服务端风险适配计算。模型答案只通过已核验事实占位符引入数字；初稿失败允许重写一次，仍失败则输出确定性摘要。研究说明与已校验模拟明细无需通过删除“买入／卖出”破坏原文。

SSE 不公开任何原始模型消息。完成事务成功后才发送 artifact、warning、完整 token 和 done；两者答案一致。事务未成功不得发送完成事件。

## 持久化、切换及验证

内部 checkpoint ID 为 `advisor-v2:{session_id}:{request_id}`，公开会话 ID 不变。业务数据库提供公开历史；恢复读取最新确认画像，成功任务不会重复执行。

部署前停止旧实例接收请求、等待运行段结束，执行 `python -m scripts.migrate`，再启动新实例。`007_advisor_v2.sql` 为幂等 DDL，增加会话上下文、图版本、证据任务归属、配置任务归属及完整生成快照。方案整批写入与生成快照使用同一事务，按生成身份加事务锁；中途失败整批回滚，同键恢复重放完整结果。旧完成轮次、方案和成交保留；旧活动轮次在新入口被作废并解除会话锁，返回 `graph_version_changed` 提示重新发送。
